# Interview Prep Platform

An outcome-evidence coach for job interviews. It turns a candidate's CV into evidence they can tell and defend, probes for what the role expects, and rehearses them across every interview format, including self-taped one-way video.

- **Status:** specification complete; Phase 0 (foundations) next.
- **Launch market:** New Zealand first, then Australia, then others. Serves any job and industry.
- **Specification:** see [`docs/spec/`](docs/spec/), starting with [`01-master-spec.md`](docs/spec/01-master-spec.md).
